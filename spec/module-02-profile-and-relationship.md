# M02 档案与指导关系 Spec

> 状态：待实现 · 范围依据 [mvp1-scope.md](mvp1-scope.md) v1.0 第 3、5、9 节及 `context.md` 第 3、4、12 节
> AC 编号 `AC-02-NN`；写法约定与演示数据见 [mvp1-scope.md](mvp1-scope.md) 第 6、8 节。

## 1. 目标与边界

**做**：学员维护训练条件与目标；教练维护自己的资料；建立与结束教练—学员的指导关系；以该关系作为所有指导数据的访问边界。

**不做**：指导申请审批流、自动匹配教练、教练团队、公开教练主页与评价、档案字段的完整自定义（Out of Scope）。指导关系的**建立方式仍待确认**（学员申请或管理员分配，见第 7 节），本 Spec 只依赖"关系已建立 / 已结束"这两个状态，不预设流程。

## 2. 最小字段集（本版可测试所需）

| 对象 | 字段 |
| --- | --- |
| 学员档案 | 训练目标、训练经验、每周可训练次数、可用器械 |
| 教练资料 | 姓名/显示名、简介 |
| 指导关系 | 学员、负责教练、状态（生效 / 已结束）、建立时间 |

扩展字段待确认；字段增减不新增模块，但需按 mvp1-scope.md 第 7 节更新本文档。

## 3. 角色与权限

| 角色 | 允许 | 拒绝 |
| --- | --- | --- |
| 学员 | 读写自己的档案；查看负责自己的教练资料 | 修改他人档案、查看他人指导关系、自行指定教练 |
| 教练 | 查看负责学员档案、维护自己的资料、结束自己名下的指导关系 | 查看无关系学员档案、修改学员档案内容 |
| 管理员 | 无（账号层面操作在 M09） | 读写档案与指导数据 |

## 4. 前置条件

T-001、T-002、C-001、C-002 账号启用并已登录可认证；T-001 档案初始为未完善；指导关系初始状态见各 AC 的 Given。

## 5. 验收标准

**AC-02-01 `[正常流]` 学员完善档案**
**Given** T-001 已登录，档案尚未完善
**When** T-001 填写训练目标"增肌"、训练经验"初级"、每周可训练次数 3、可用器械"哑铃"并保存
**Then** 四项字段被持久化，且 T-001 再次查看时显示相同值，且负责教练 C-001 可查看到这四项字段

**AC-02-02 `[异常流]` 必填缺失**
**Given** T-001 已登录，档案尚未完善
**When** T-001 只填写训练目标后保存，其余三项为空
**Then** 保存被拒绝，且提示中明确指出缺失的字段名称，且不产生只有部分字段的档案记录

**AC-02-03 `[权限]` 学员改他人档案**
**Given** T-001 已登录
**When** T-001 绕过界面直接提交修改 T-002 档案的请求
**Then** 服务端返回拒绝（权限不足），且 T-002 档案各字段保持不变

**AC-02-04 `[权限]` 无关系教练查看档案**
**Given** C-002 已登录，且与 T-001 无生效的指导关系
**When** C-002 绕过界面直接请求 T-001 的档案
**Then** 服务端返回拒绝（权限不足），且响应中不含 T-001 的目标、经验、次数或器械字段

**AC-02-05 `[正常流]` 建立指导关系**
**Given** A-001 或已确认的建立方式可用，且 C-001 与 T-001 之间当前无生效关系
**When** 建立 C-001 负责 T-001 的指导关系
**Then** 该关系状态为"生效"并记录建立时间，且 C-001 的负责学员列表出现 T-001，且 T-001 可见其负责教练为 C-001，且 C-002 仍无法访问 T-001 档案

**AC-02-06 `[正常流] [历史一致性]` 结束指导关系**
**Given** C-001 与 T-001 的关系为"生效"，且 T-001 已有针对 P-001 的执行记录 R-001 与反馈
**When** C-001 结束该指导关系
**Then** 关系状态变为"已结束"，且 T-001 不再出现在 C-001 的生效负责学员列表，且 C-001 不能再新建 T-001 的计划，且 R-001 及其反馈仍可按历史查询且内容不变

**AC-02-07 `[异常流]` 已结束关系下继续提交**
**Given** C-001 与 T-001 的关系为"已结束"
**When** T-001 针对该关系提交一条新的训练执行记录
**Then** 服务端拒绝该提交并说明指导关系已结束，且不产生新记录，且已有历史记录不受影响

**AC-02-08 `[异常流]` 重复建立生效关系**
**Given** C-001 与 T-001 已存在一条"生效"关系
**When** 再次为二者建立指导关系（无论建立方式如何）
**Then** 服务端拒绝并提示关系已存在，且生效关系条数仍为 1

## 6. 与其他模块的依赖

- 依赖 M01：角色判定与会话；依赖 M09：账号存在且角色正确。
- 被依赖：M03–M08 的"负责教练 / 自己的学员"判定全部以本模块的关系状态为准。
- 关系状态变化不得删除历史业务数据；历史一致性由 M03、M08 的 AC 继续验证。

## 7. 待确认项（不阻塞范围锁定）

- 指导关系由学员申请还是管理员分配、结束与重新分配规则、一名学员是否限一名负责教练：AC-02-05 的 Given 以"已确认的建立方式可用"表达，规则确定后只替换该处，不改动 AC 判定部分。
- 学员档案是否需要更多字段（如伤病史）：待确认；如纳入需走范围变更流程，并评估隐私约束。

## 8. 不在本模块范围

体重数值记录（M06）、进度趋势计算（M08）、账号启停与角色分配（M09）、AI 依据档案生成草稿的输入契约（M04/M05 各自定义，但字段取自本模块最小字段集）。
