# M07 沟通反馈 Spec

> 状态：待实现 · 范围依据 [mvp1-scope.md](mvp1-scope.md) v1.0 第 3、4、5 节及 `context.md` 5.1、5.2、10 节
> AC 编号 `AC-07-NN`；写法约定与演示数据见 [mvp1-scope.md](mvp1-scope.md) 第 6、8 节。

## 1. 目标与边界

**做**：学员围绕自己的一条训练或饮食执行记录提出问题；负责教练查看记录并回复、给出指导意见；学员查看反馈及历史交流。

**不做**：完整即时聊天系统、群聊、直播/视频/语音、推送通知、附件与图片、消息已读状态、AI 自动回复（Out of Scope）。沟通**围绕执行记录**展开，不建设独立会话列表或私信系统。

## 2. 关键规则

- 每条提问必须关联到学员本人的一条执行记录；反馈关联到该提问。
- 交流内容对该学员与其负责教练可见；其他学员、非负责教练、管理员均不可见。
- 指导关系结束后，历史交流仍可查询，但不能新增提问或回复（与 M02 AC-02-06、AC-02-07 一致）。
- 反馈不改变执行记录内容，也不改变已发布计划。

## 3. 角色与权限

| 角色 | 允许 | 拒绝 |
| --- | --- | --- |
| 学员 | 针对自己的记录提问、查看自己交流的反馈与历史 | 针对他人记录提问、删除他人内容 |
| 负责教练 | 查看负责学员的记录与提问、回复、给指导意见 | 回复无关系学员、修改学员提问 |
| 管理员 | 无 | 查看私人交流内容 |

## 4. 前置条件

C-001 与 T-001 关系生效；R-001 为 T-001 针对 P-001 的训练执行记录；T-002 与 C-002 与 T-001 无关联。

## 5. 验收标准

**AC-07-01 `[正常流]` 学员围绕记录提问**
**Given** T-001 已登录，R-001 为本人执行记录
**When** T-001 针对 R-001 提交问题"第三组没完成，需要补练吗？"
**Then** 产生一条关联 R-001 的提问，且提问内容、提问人与时间被保存，且 C-001 可在该记录下看到该提问，且 R-001 内容不变

**AC-07-02 `[正常流]` 教练查看记录并反馈**
**Given** C-001 已登录且负责 T-001，存在 AC-07-01 产生的提问
**When** C-001 查看 R-001 并提交回复"本周不补练，下周期降低组数"
**Then** 产生一条关联该提问的反馈，且反馈内容、回复人与时间被保存，且 T-001 可查看到该反馈，且 P-001 与 R-001 内容均不变

**AC-07-03 `[正常流]` 查看历史交流**
**Given** T-001 存在多条针对不同执行记录的提问及其教练反馈
**When** T-001 查询历史交流
**Then** 每条交流都显示关联的执行记录、提问与反馈内容及时间，且不包含其他学员的交流，且顺序可按时间追溯

**AC-07-04 `[权限]` 其他学员查看交流**
**Given** T-002 已登录
**When** T-002 绕过界面直接请求 R-001 下的提问与反馈
**Then** 服务端返回拒绝（权限不足），且响应中不含任何提问或反馈正文

**AC-07-05 `[权限]` 非负责教练回复**
**Given** C-002 已登录且与 T-001 无生效指导关系
**When** C-002 绕过界面直接请求回复 R-001 下的提问
**Then** 服务端返回拒绝（权限不足），且不产生反馈，且响应中不含 R-001 的内容

**AC-07-06 `[权限]` 管理员查看私人交流**
**Given** A-001 已登录
**When** A-001 绕过界面直接请求 R-001 下的交流内容
**Then** 服务端返回拒绝（权限不足），且响应中不含提问或反馈正文

**AC-07-07 `[异常流]` 空内容提交**
**Given** T-001 已登录，R-001 存在
**When** T-001 提交空白提问，或 C-001 提交空白反馈
**Then** 提交被拒绝并提示内容不能为空，且不产生提问或反馈记录

**AC-07-08 `[异常流]` 关联无效记录**
**Given** T-001 已登录
**When** T-001 绕过界面直接请求针对 T-002 的某条记录、或一条不存在的记录提交提问
**Then** 服务端拒绝并说明关联对象无效，且不产生提问，且不泄露该记录是否存在的内容信息

**AC-07-09 `[异常流]` 关系结束后新增交流**
**Given** C-001 与 T-001 的指导关系为"已结束"，且存在历史交流
**When** T-001 尝试新增提问，或 C-001 尝试新增回复
**Then** 服务端拒绝并提示指导关系已结束，且历史提问与反馈仍可查询且内容不变

## 6. 与其他模块的依赖

- 依赖 M01（服务端权限）、M02（生效指导关系及其结束状态）、M06（作为提问锚点的执行记录）。
- 被依赖：M08 在查询历史计划与反馈时展示本模块的反馈内容；`context.md` 第 10 节"教练能够反馈"由本模块落地。
- 与 M03/M05 的关系：反馈只是意见，不触发计划或建议的自动改写；调整下一周期由教练显式操作。

## 7. 待确认项

- 是否允许教练在无提问时主动给指导意见：当前 `context.md` 5.2 允许"教练查看执行记录并回复、反馈"，本版 AC 只覆盖有提问的回复；主动意见的表达方式待确认，不新增模块。
- 单人单条记录下的交流条数上限、是否允许编辑已发内容：待确认。

## 8. 不在本模块范围

即时通讯与在线状态、通知推送、图片与文件附件、AI 自动反馈、执行记录提交（M06）、进度计算（M08）、计划调整（M03）。
